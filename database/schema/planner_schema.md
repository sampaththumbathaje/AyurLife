# Dinacharya Planner Schema – AyurLife

## Collection Name
`dinacharya`

## Description
The `dinacharya` collection stores predefined Ayurvedic daily routine tasks (Dinacharya) that are recommended to users based on Ayurvedic principles.  
These tasks are used by the Daily Dinacharya Planner module to promote holistic lifestyle management.

User-specific completion tracking is stored separately in the `users` collection.

---

## Fields Overview

### 1. `_id`
- **Type:** ObjectId
- **Description:** Unique identifier generated by MongoDB.

---

### 2. `task_id`
- **Type:** String
- **Description:** Application-level unique identifier for the Dinacharya task.
- **Example:** `D001`

---

### 3. `task_name`
- **Type:** String
- **Description:** Name of the daily routine activity.
- **Example:** Wake up before sunrise (Brahma Muhurta)

---

### 4. `description`
- **Type:** String
- **Description:** Detailed explanation of the task and its Ayurvedic significance.

---

### 5. `recommended_time`
- **Type:** String
- **Description:** Suggested time to perform the activity.
- **Example:** `05:30`

---

### 6. `category`
- **Type:** String
- **Description:** Classification of the task.
- **Examples:** Morning Routine, Oral Care, Body Care

---

## Benefits & Suitability

### 7. `benefits`
- **Type:** Array of Strings
- **Description:** Health benefits associated with performing the task regularly.

---

### 8. `suitable_prakriti`
- **Type:** Array of Strings
- **Allowed Values:** `Vata`, `Pitta`, `Kapha`
- **Description:** Prakriti types for which the task is recommended.

---

### 9. `frequency`
- **Type:** String
- **Description:** Frequency of the task.
- **Example:** `daily`

---

## Metadata

### 10. `created_at`
- **Type:** ISODate
- **Description:** Task creation timestamp.

### 11. `updated_at`
- **Type:** ISODate
- **Description:** Task last update timestamp.

---

## Relationship with Users

- The `dinacharya` collection stores **template tasks only**.
- User-specific scheduling and completion status are stored in:
  - `users.dinacharya_planner`

This design avoids duplication and allows reuse of tasks across all users.
