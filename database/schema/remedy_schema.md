# Remedy Schema – AyurLife

## Collection Name
`remedies`

## Description
The `remedies` collection stores detailed information about Ayurvedic formulations recommended by the system.  
It acts as a **structured knowledge base** that complements the machine learning model’s predictions and enables chatbot explanations, dashboard bookmarking, and herb linking.

---

## Fields Overview

### 1. `_id`
- **Type:** ObjectId
- **Description:** Unique identifier generated by MongoDB.

---

### 2. `remedy_id`
- **Type:** String
- **Description:** Application-level unique identifier for the remedy.
- **Example:** `R001`

---

### 3. `name`
- **Type:** String
- **Description:** Name of the Ayurvedic remedy.
- **Note:** This field must exactly match the ML model output.

---

### 4. `category`
- **Type:** String
- **Description:** Health category of the remedy.
- **Example:** Digestive Health, Respiratory Health

---

## Therapeutic Information

### 5. `used_for`
- **Type:** Array of Strings
- **Description:** List of symptoms or conditions treated by the remedy.

---

### 6. `ingredients`
- **Type:** Array of Objects
- **Description:** Herbs used in the formulation.

#### Subfields:
| Field | Type | Description |
|------|------|------------|
| `herb_id` | String | Reference to herb |
| `name` | String | Herb name |

---

## Dosage & Safety

### 7. `dosage`
- **Type:** Object
- **Description:** Recommended usage details.

#### Subfields:
| Field | Type | Description |
|------|------|------------|
| `adult` | String | Adult dosage |
| `child` | String | Child dosage |
| `duration` | String | Treatment duration |

---

### 8. `precautions`
- **Type:** Array of Strings
- **Description:** Safety precautions while using the remedy.

---

### 9. `side_effects`
- **Type:** Array of Strings
- **Description:** Known side effects (if any).

---

### 10. `contraindications`
- **Type:** Array of Strings
- **Description:** Conditions where the remedy should be avoided.

---

## Prakriti Compatibility

### 11. `suitable_prakriti`
- **Type:** Array of Strings
- **Allowed Values:** `Vata`, `Pitta`, `Kapha`
- **Description:** Prakriti types for which the remedy is suitable.

---

## References

### 12. `references`
- **Type:** Array of Strings
- **Description:** Classical Ayurvedic texts supporting the formulation.

---

## Metadata

### 13. `created_at`
- **Type:** ISODate
- **Description:** Record creation timestamp.

### 14. `updated_at`
- **Type:** ISODate
- **Description:** Last update timestamp.

---

## Design Considerations

- Remedy name acts as a **bridge between ML output and database lookup**.
- Ingredient references link remedies to the herb knowledge base.
- Structured fields support chatbot explanation and dashboard visualization.
- Enables filtering by symptoms, Prakriti, and category.
